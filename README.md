Мини-сервер `pprof-lab` с «тяжёлыми» функциями, профили CPU / Heap / Block / Mutex,
ручные таймеры, бенчмарки и оптимизация с замерами «до/после».

## Эндпоинты

| Путь | Нагрузка | slow («до») | fast («после») |
|---|---|---|---|
| `/work?n=38&impl=slow\|fast`   | CPU    | `Fib` — рекурсия, O(2ⁿ) | `FibFast` — цикл, O(n) |
| `/report?n=2000&impl=slow\|fast` | память | `s += fmt.Sprintf(...)` | `strings.Builder` + `Grow` + `strconv.AppendInt` |
| `/lock?impl=slow\|fast`        | мьютекс | работа под `mu.Lock()` | работа вне критической секции |
| `/debug/pprof/`                | профили pprof (`net/http/pprof`) | | |

Режим задаётся параметром `impl` (или переменной окружения `IMPL=fast`).
Block/Mutex-профили включены в `main.go` (`runtime.SetBlockProfileRate(1)`, `SetMutexProfileFraction(1)`).

## Как повторить

```bash
make tools          # hey + benchstat
make run            # терминал 1: сервер на :8080
make profile-all    # терминал 2: нагрузка + профили slow и fast -> profiles/{slow,fast}/
make bench          # бенчмарки -benchmem -count=5 -> bench.txt
make pprof-cpu      # веб-интерфейс pprof (Graph, Flame Graph) на :9999
```

> Чтобы профили allocs/block/mutex у режимов не смешивались, `scripts/profile.sh` снимает
> **дельта-профили** (`?seconds=N`) только за время своей нагрузки. Для чистоты сервер
> перезапускался между прогонами slow и fast.

## Результаты (Go 1.24.7, 2 vCPU)

| Бенчмарк | до: ns/op | после: ns/op | ускорение | B/op до → после | allocs/op до → после |
|---|---:|---:|---:|---|---|
| Fib(30)            | 3 712 902 | 21.6    | ≈172 000× | 0 → 0 | 0 → 0 |
| BuildReport(2000)  | 5 661 352 | 30 717  | ≈184×     | 19 361 339 → 24 576 | 5 760 → 1 |
| Store.Hit (8 горутин) | 2 247 920 | 285 960 | ≈7.9× | 3 → 0 | 0 → 0 |

| Нагрузка `hey` | до: RPS | после: RPS | средняя задержка до → после |
|---|---:|---:|---|
| /work (8 клиентов)   | 10.8  | 32 461 | 734 мс → 0.2 мс |
| /report (8 клиентов) | 134   | 16 101 | 59.7 мс → 0.5 мс |
| /lock (32 клиента)   | 398   | 10 082 | 80.2 мс → 3.2 мс |

Полные выводы — в `profiles/` и `bench.txt`, отчёт — в `report/`.
